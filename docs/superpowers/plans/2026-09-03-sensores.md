# Sensores Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rugosidad, impactos y perfil de velocidad desde los sensores del celular durante el recorrido, con asignación por tramo y visualización en el mapa.

**Architecture:** `lib/sensores/` puro (calibración de gravedad, proyección vertical, agregador de segmentos, detector de impactos) alimentado por `hooks/useSensores.ts` (DeviceMotion + puntos GPS del grabador) y persistido en IndexedDB v3. Payload extendido → `finalizarRecorrido` asigna tramo, inserta `muestras_sensor` e impactos como observaciones `origen = 'sensor'`. Dashboard lee `rugosidad_tramos`.

**Spec:** `docs/superpowers/specs/2026-09-03-sensores-design.md`. Convenciones del proyecto (`docs/system-prompt.md`).
